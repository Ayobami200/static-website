Where Can You Deploy This?

Since it's pure static code, you can test on any provider in under 2 minutes.

Easiest

GitHub Pages

Push to a repository, go to Settings > Pages, and select the main branch. Live in seconds.

Fast

Vercel or Netlify

Connect your Git provider or drag and drop this project folder straight into their web dashboards.

Cloud

AWS S3 & CloudFront

Upload files to an S3 bucket configured for static website hosting, then front with CloudFront for global SSL/CDN.

DevOps

Docker & Nginx

Run docker build -t static-site . using the included Dockerfile and deploy to ECS, Render, or any VPS.
